# Экспертная система диагностики автомобиля

Учебное приложение для лабораторных 3 и 4. Python принимает ответы и применяет продукционные правила; HTML/CSS/JavaScript показывают пошаговый опрос. Работает локально, без LLM, интернета и сторонних библиотек.

## Запуск

Нужен Python 3.10 или новее. Распакуйте архив, откройте терминал в папке `auto_expert`:

```bash
python app.py
```

В Windows также можно выполнить `py app.py`, в Linux — `python3 app.py`.
Откройте в браузере **http://127.0.0.1:8000**. Остановить сервер: Ctrl+C.
Если порт занят: `python app.py --port 8001`, затем откройте адрес с портом 8001.
Не открывайте `static/index.html` двойным щелчком: интерфейсу нужен работающий Python-сервер.

## Как пользоваться

1. Выберите основную жалобу из 10 направлений.
2. Ответьте на вопросы. «Не знаю» оставляет признак неизвестным и не означает «нет».
3. В результате будут возможные причины и узел; раскройте «Почему получен этот вывод» для просмотра признаков и номера правила.
4. «Изменить ответы» возвращает к предыдущему вопросу. После изменения вывод пересчитывается с нуля.
5. «База знаний» показывает все 60 правил с поиском. Результат можно скачать в текстовый файл.

Вывод является предварительной гипотезой. Система не подтверждает диагноз и не вычисляет вероятности. Выбирайте признаки по уже известным наблюдениям; приложение не требует разбирать автомобиль или проводить опасные проверки. Отсутствие подходящего правила не означает исправность. Ветвь трансмиссии предназначена только для механической коробки. Ремонтные рекомендации для лабораторной 5 пока не реализованы.

## Файлы

- `app.py` — HTTP-сервер и API, привязанный к 127.0.0.1.
- `engine.py` — валидация, прямой продукционный вывод, выбор следующего вопроса.
- `data/knowledge.json` — 10 категорий, 61 вопрос, 60 правил, проверки противоречий.
- `static/index.html`, `style.css`, `app.js` — интерфейс без сборщика.
- `tests/scenarios.json` — 20 контрольных примеров с ожидаемыми выводами.
- `tests/test_system.py` — автоматические проверки сценариев, API и свойств системы.
- `tests/results.json` — фактические результаты последнего запуска сценариев.
- `docs/` — отчёты и описание структуры базы знаний.

## Проверка

Из папки `auto_expert`:

```bash
python -m unittest discover -s tests -v
```

Проверяются 20 диалогов, все 46 конечных выводов, неизвестные ответы, противоречия, повторный вывод после изменения ответа, валидация данных, API и статические ресурсы. В тестах отсутствуют реальные данные автомобилей: они проверяют логику программы, а не диагностическую точность.

Перед демонстрацией откройте приложение в своём браузере и проверьте кнопки, возврат, окно базы знаний и скачивание результата. Автоматические проверки этого пакета не заменяют визуальную проверку браузера.

## Связь с лабораторной 2

Номера 1–60 сохранены. 14 правил дают промежуточные факты, 46 — конечные выводы. Условия предшествующих правил учитываются автоматически. Вход правила 19 уточнён до «необычный дым или пар» без ограничения прогревом: иначе правило 24 о холодном паре было бы недостижимо. Входная жалоба выбирается пользователем и считается известным фактом; дальнейшие признаки уточняются вопросами.

Это диалог по правилам с динамическим выбором вопросов, а не обученное статистическое дерево и не алгоритм машинного обучения. Порядок задаётся приоритетами вопросов и их применимостью; признаки, относящиеся к уже исключённым выводам, не запрашиваются. Система продолжает уточнение, чтобы обнаружить и другие совпадающие правила, а не останавливается на первой гипотезе.

## API

`GET /api/knowledge` возвращает категории и правила.

`POST /api/consult`:

```json
{"category":"start","answers":{"starter":"slow"}}
```

Возвращает `question` для следующего шага либо `results` и конечный `status`:

- `question` — нужен следующий ответ;
- `matched` — есть полностью сработавшие конечные правила;
- `insufficient` — неизвестные признаки не позволяют сделать вывод;
- `no_match` — все конечные правила исключены известными ответами.

HTTP 400 возвращается для неизвестной категории, чужого вопроса, недопустимого значения или обнаруженного противоречия. Сервер не хранит сессии: ответы передаются из браузера на каждом шаге. После обновления страницы опрос начинается заново.
